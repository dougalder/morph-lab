format

Sets the shape everything crops to — pick one before uploading to start there, or switch any time to re-crop. "Auto" just uses your first image's own shape.

export settings

MP4 plays everywhere but can't carry transparency — any transparent area renders as solid black. WebM keeps real transparency (handy for "export PNG sequence" alternatives or compositing), but isn't supported by every video player/editor.

face mode

Automatically finds ~40 facial landmarks (eyes, brows, nose, mouth, jaw) on each image instead of clicking points by hand. Every point is still fully draggable afterward — this is a starting point, not a final answer. Runs on CPU, so it isn't tied to the same WebGL issue as the renderer — but detection speed and reliability across browsers hasn't been tested here.
