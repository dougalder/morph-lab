🌀 Morph Lab

Create smooth, professional image morphing videos in your browser.
No uploads, everything runs locally.

  • Mark matching points between two images
  • Automatic face detection (optional)
  • Smooth morphing animation with adjustable timing
  • Export as MP4, WebM, or PNG sequence
  • Customizable aspect ratios (auto, 1:1, 16:9, 9:16, 4:3, 3:4)
  • Light & dark mode
  • Works in Chrome, Edge, Firefox, Safari
Browser Requirements: Modern browser with WebGL support. Safari uses a fallback Canvas2D renderer for compatibility.
Launch App (Recommended) Safari Fallback
Tip: The recommended version uses WebGL for better performance. If you experience issues in Safari, use the fallback version which uses Canvas2D rendering.
